
*В модуле присутствует кэширование, выполняется один запрос по API для получения списка дорожек озвучки, сезонов и серий. Далее данные берутся из кэша. При клике на дорожку озвучки подгружаются доступные для просмотра сезоны и серии для данной озвучки. При выборе сезона загружается список серий данного сезона. При выборе серии подгружается плеер для выбранной серии, а информация о выбранной озвучке, сезоне и серии сохраняется в куки браузера. Таким образом, при последующем посещении страницы сериала посетитель увидит информацию о последнем просмотренном месте, например: "Ходячие мертвецы. Вы остановились на 3 сезоне, 4 серии в озвучке «Fox»".


Установка:

1. Залить файл alloha_playlist.css в папку css вашего шаблона и подключить в main.tpl кодом
HTML:

[aviable=showfull]<link href="{THEME}/css/alloha_playlist.css" type="text/css" rel="stylesheet" />[/aviable]

2. Залить файл alloha_playlist.js в папку js вашего шаблона и подключить в main.tpl кодом
HTML:
[aviable=showfull]<script type="text/javascript" src="{THEME}/js/alloha_playlist.js"></script>[/aviable]

3. Открываем плагин dle-alloha-series.xml, ищем в нем https://ekbert.allohastream.com - заменяем на свой домен плеера

4. В showfull.tpl в нужном месте где будет выводиться плейлист вставить код

<div id="alloha_player_ajax" data-kinopoisk_id="[xfvalue_доп_поле_с_kinopoisk_id]" data-news_id="{news-id}" data-with_seasons="1" ></div>

Вместо "доп_поле_с_kinopoisk_id" вставляем латинское название доп поля которое содержит в себе id КиноПоиска.
Не забудьте код обернуть в теги [catlist=x]код плеера[/catlist] или в [xfgiven_x]

Параметр data-with_seasons="0" скрывает выбор сезонов
Параметр data-with_seasons="1" показывает выбор сезонов

Вместо kinopoisk_id вы можете указать id с других баз:

kinopoisk_id
imdb_id
tmdb_id
world_art_id
или token_movie - ID фильма в базе Alloha

Плейлист адаптивный. С телефона список серий пролистывается вправо и влево пальцем по экрану. Стили можно настроить под ваш сайт. В плейлисте используются иконки Font Awesome. Если вы не видите иконки, подключите библиотеку Font Awesome к вашему сайту.
