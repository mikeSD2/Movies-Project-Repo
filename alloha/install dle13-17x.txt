УСТАНОВКА:

1. Установите плагин через админку DLE в разделе /admin.php?mod=plugins - "загрузить плагин".

ВНИМАНИЕ: Для DLE 15.1 - Вкключите все чекбоксы в плагине:

https://i.postimg.cc/7LRqqCMX/screenshot-30jan2022-16-31-20.png

2. Загрузите все файлы из папки engine/data. Установите права на запись для папок engine и engine/data - 777. Для файлов - установите права 666.

3. Загрузите файл дополнительных полей xfields.txt из архива по пути engine/data. Или используйте свои (обязательное условие - наличие поля kinopoisk_id с именно таким названием).


ВАЖНО: 

Проверка на дубли происходит по названию поля kinopoisk_id. Главное условие - наличие поля ID Кинопоиска с названием "kinopoisk_id".

Если поле названо по-другому - не удаляйте ваше поле, иначе данные могут быть утрачены.

Сначала создайте поле kinopoisk_id, а затем выполните запрос в PHPMyAdmin для переноса идентификаторов Кинопоиска в это поле:

UPDATE dle_post SET xfields = REPLACE(xfields, 'ТУТ НАЗВАНИЕ ВАШЕГО ПОЛЯ', 'kinopoisk_id');

4. Настройте в модуле вкладки с дополнительными полями и категориями.

5. Для запуска автообновления - установите и запустите крон, например, на раз в час:

/engine/ajax/controller.php?mod=alloha&last

* если у Вас виснет при запросе - найдите в плагине:

for ($page=1; $page < 6; $page++) {

и замените "6" - на цифру ниже

6. Для автодобавления фильмов и сериалов через крон установите и запустите крон из файла "крон.txt".

7. Для форматированного вывода "+ 1 серия / сезон" в мета-тайтле укажите нужный тег из вкладки "Теги" для форматированных серий и сезонов. Данные берутся из дополнительных полей "формат. серия/сезон", поэтому эти поля также должны быть заполнены.
